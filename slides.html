Ten Starter Prompts

Ten ready-to-use AI prompts for study, work and home — and how to use them safely.

1. Before you start

Three quick rules — read these before you try any prompt.

Use an approved tool only

Only send these prompts through your institution's approved AI tool and account — not a random app.

Never type in personal data

Replace every [bracket] with your own task — never your name, ID number, address or photos.

Read the whole answer first

An AI answer is a draft, not the final word. Check it before you copy, send or act on it.

2. Study — pick a prompt

Use these before class, for revision, or to plan an assignment.

STUDY · 01–03
1
Higher ed

Explain [topic name] in simple terms, as if to a first-year student, using one everyday example. Keep it to 150 words.

2
ITI

Turn these notes into 5 short revision points I can read before a test: [paste your notes here].

3
ITI Higher ed

I have an assignment due on [date] about [topic]. Suggest a simple structure with headings, and one question to answer under each heading.

3. Work — pick a prompt

Use these for reminders, notes, emails and project planning.

5

7
Higher ed

5. See it filled in

Same prompt, before and after the brackets are replaced.

TEMPLATE (PROMPT 1)

Explain [topic name] in simple terms, as if to a first-year student, using one everyday example. Keep it to 150 words.

FILLED IN

Explain photosynthesis in simple terms, as if to a first-year student, using one everyday example. Keep it to 150 words.

A POSSIBLE AI ANSWER

"Photosynthesis is how plants make their own food. Think of a plant as a tiny kitchen: sunlight is the stove, water and carbon dioxide are the ingredients, and the plant's leaves cook them into sugar it can use for energy — giving off oxygen as a bonus."

This is only an example answer — always read your own AI's response fully and check any fact before you use it.
